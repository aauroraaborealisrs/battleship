## Installation
1. git clone [https://github.com/aauroraaborealisrs/battleship](https://github.com/aauroraaborealisrs/battleship.git)
2. cd battleship
3. git checkout dev
4. npm install

## Usage
**Development**

`npm run start:dev`

* App served @ `http://localhost:3000`

**Production**

`npm run start`

* App served @ `http://localhost:3000`
